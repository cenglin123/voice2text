## 范围与设计

- 应用先于 UIAutomation/Tk 显式声明 PMv1，system_scale 不能代表窗口所在屏幕。
  使用 GetDpiForWindow，并在窗口创建/定位后读取；旧系统回退系统倍率。
- 设置窗口按当前屏幕工作区限制宽高，移除按屏宽降低 DPI 的做法；保持固定页脚、内容滚动。
- 常规只放快捷键、提示音、自启动；识别页只放麦克风和校对；更新与运行输出放关于页。
- 修复预览中混用固定像素与 DPI 像素的位置；页面分组后减少常规页面滚动。
- 悬浮窗跨屏更新倍率，托盘每次弹出按弹出位置重新读取倍率；不改识别、热键和上屏链路。
- 本阶段设置页在打开时选择正确屏幕倍率；跨屏后的实时重排如未实现，明确记录边界，
  不把模拟回归标为用户高 DPI 真机验收通过。
