# 自包含分发版一键更新

## 目标

设置页可检查 GitHub 最新正式 Release，下载与当前架构匹配的自包含 ZIP，验证 SHA-256 和
压缩包结构。用户确认后退出当前程序，由独立 PowerShell 更新器覆盖安装目录并自动重启。

## 约束

- 固定仓库 `cenglin123/voice2text`、HTTPS 和 Windows x64 资产命名，不执行远端脚本。
- 仅 `offline-bundle.txt` 标记的自包含分发版允许安装更新；源码开发环境只提示不执行。
- 保留 `config.json` 和 `models/llm/` 可选校对模型。
- 当前 Python 退出后再覆盖 `runtime/`，避免 Windows 文件锁。
- 下载写入用户 LocalAppData，使用 `.part` 临时文件；校验失败不得启动更新器。

## 实现与验收

1. 后台查询 Releases API，比较语义版本，选择 ZIP 与同名 `.sha256`。
2. 流式下载并显示进度，校验摘要、单一根目录、版本和路径穿越。
3. 设置页显示当前版本、状态和“检查更新/安装并重启”。
4. 本地更新脚本等待当前 PID 退出，合并新包并恢复用户配置和校对模型，随后启动 `run.bat`。
5. 单元回归覆盖版本比较、资产选择、摘要、ZIP 结构和恶意路径；发行检查保证更新模块与脚本入包。

## 风险

- GitHub 不可达时保留当前版本并允许重试。
- 更新中断可能留下部分覆盖；更新脚本先完整解压并验证根目录，再开始复制。
- 首版不做后台自动更新，只在用户从设置页主动发起时联网和安装。

## 实施结果

- 设置页已接入版本、下载进度、失败重试和“安装并重启”。
- 更新包使用固定仓库 HTTPS 资产与 SHA-256，安装前检查路径、符号链接、数量、体积和内部版本。
- 临时安装目录集成测试确认新文件生效，原 `config.json` 和 `models/llm/` 保留。
- 更新模块和 PowerShell 脚本已纳入发行白名单；仍需在发布 v0.1.2 后用真实 Release 做端到端验收。
