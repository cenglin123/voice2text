# 每 24 小时自动更新

用户明确授权自动检测 GitHub 新版本并自动更新，间隔 24 小时；无需再次询问安装许可。

| 阶段 | 状态 | 验收 |
|---|---|---|
| 方案独立复查 | completed | 调度、空闲安装与关闭开关边界 |
| 更新器调度与持久化 | completed | 启动到期检查、24h跨重启节流、失败节流、单任务和安全退出 |
| 主循环及设置接入 | completed | 默认开启、可关闭、后台下载、听写/校对/模型下载/设置打开期间延后重启 |
| 焦点失败显式提示 | completed | 不激活提示卡保留具体原因，待命复位不提前清除，新听写清除 |
| 集成验证与复查 | completed | 假时钟/网络回归、现有更新安装回归、设置与发行回归、完工检查 |

复用固定 GitHub Latest 正式版本、SHA256、ZIP校验与安装脚本，保留配置和可选模型。
仅自包含分发版自动更新，源码环境不联网自更新。保存每个安装目录的检查时间，失败不密集重试；
手动检查不受24小时限制。网络与校验都在后台线程，主循环不加载或校验大包。
下载完成后只在程序安全空闲时安装并重启；设置窗口打开时也延后，避免未保存改动丢失。
关闭自动更新期间不检查或自动安装已下载包；再次开启后恢复自动更新，已验证包仍可手动安装。
本轮实现源码并提交，不自动发布新版本，除非用户进一步要求。

用户追加要求：目标输入框未聚焦导致不能开始时，必须直接显示原因，不能仅日志反馈。
