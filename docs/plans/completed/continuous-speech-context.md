# 连续讲话的语义分段与上下文校对

## 验收目标

1. 20 秒 ASR 强制重置不等同句号；用户持续讲话时无需人为停顿，原文持续上屏。
2. 自然停顿与停止时，标点模型可参考有限的既有文本，但只允许向当前段插入标点，绝不改动历史段。
3. 停止后的校对块读取前后相邻原文作为只读上下文，只替换本块；模型输出不可靠时保留原文。
4. 音频、文本与推理内存有明确边界；长时间讲话后仍能停止并完成安全清理。

## 实现与取舍

- ASR 的 rule3 仍在 20 秒重置流，按已接受音频时长保守判定强制分段；强制分段允许段内
  标点，但移除模型臆测的句末符号。对恰好发生在 20 秒附近的真实停顿，优先漏掉即时句末标点，
  停止后的校对负责补齐。
- 标点恢复拼接前一小段文本作为只读提示；字符投影只保留当前段的新增标点。
- 校对采用原始文本中的前后邻接上下文，不让已校对块的输出污染后续模型输入。
  小模型输出必须仅包含目标块；无法可靠确认时保留原文。
- 听写期间保留当前的已上屏文字安全策略。跨段内部标点只有在停止后的校对阶段才可能补齐，
  不为了提前加标点而在听写中回写历史文本。

## 验证

- 离线模拟 20 秒强制切段、自然停顿、长连续句、识别末句、上屏失败与标点投影。
- 模拟带前后上下文的校对及非法输出，核对替换范围、长度门禁和停止超时。
- 执行 `python scripts/check_all.py --quiet`，更新 bugfix 档案、CURRENT 和 CHANGELOG。

## 完成情况

- 92 项会话回归通过，覆盖 20 秒强制切段、切段后继续识别、只读标点上下文、
  上下文改字回退、校对块邻接语境和连续块末尾标点。
- 本地标点模型可在带历史语境时正常返回；本地 Qwen3-1.7B 样例只输出目标段并加入内部逗号。
- `python scripts/check_all.py --quiet` 通过。真实长时间语音、不同说话速度及微信/WPS 等目标
  仍需设备验收；小模型的语意判断仍可能犯错，安全门禁会拒绝改字的标点结果。
