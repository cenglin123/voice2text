# 桌面常驻、目标锁定与圆角修复

用户授权四项：消除毛玻璃圆角蓝底/锯齿、兼容 OpenCode TUI、按 DSH tray 常驻并从右键打开调试输出、从开始到校对结束固定输出位置。用户明确选择保持原窗口焦点直到校对结束。

## 设计

1. 圆角：分离系统模糊承载面与抗锯齿内容面，模糊边界向内收缩，外缘由逐像素 alpha 覆盖；以实际屏幕截图检查。
2. 会话目标：开始请求时捕获前台窗口及焦点控件身份；保持前台、每批注入前核对身份，无法恢复或目标消失则停写。终端按真实窗口类识别，不靠 Edit/ValuePattern 判断 TUI 可输入性。
3. 常驻：参考本机 DSH tray 源码的隐藏启动、单实例、受限输出缓存和菜单日志窗；默认 pythonw 启动，保留显式 debug 控制台入口，不隐藏调用者已有终端。
4. 生命周期：目标锁定覆盖初始化、尾句排空、校对和异常清理。退出必须关写入闸门；会话代数在尾句排空后失效，避免尾句被提前丢弃。

## 验收

- 新鲜视角审查目标锁定与原生资源，改动后独立复核。
- 两个编辑目标/终端身份模拟验证：切焦点、恢复失败、同窗不同控件、目标关闭、尾句、校对、退出迟到回调均不得错写。
- 桌面预览核对四角；透明度、缩放、移动、显隐无残留底。
- 无控制台启动、单实例、托盘调试窗口有实时输出且关闭不退出常驻。
- 运行针对性验证及 `python scripts/check_all.py --quiet`，沉淀 bugfix 并提交。
