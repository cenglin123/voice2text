## 实施边界

- 维持深蓝玻璃视觉、红色听写反馈、现有热键与离线听写行为。
- 将悬浮窗绘制部分与窗口呈现分开；预览直接按设置和所选状态重绘，不裁切当前截图。
- 方形布局优先保证按钮、麦克风和完整状态文案；声波条数根据可用空间确定。
- 托盘保留紧凑尺寸；根据真实文字宽度分配快捷键区域，去掉暗示存在子菜单的箭头。
- 下载/更新按钮在不可操作时禁用，并具备可见键盘焦点。
- v0.1.5 纳入上一阶段 DPI/设置页修复；高 DPI 笔记本/混合 DPI 双屏仍待用户验收。
- 不改治理准则文件、不提交用户 config.json、不默认提权、不加载云端推理。
