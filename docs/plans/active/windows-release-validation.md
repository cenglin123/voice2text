# Windows 分发版制作与虚拟机验收

## 目标

生成自包含 Windows x64 分发包：独立 Python、全部依赖、语音识别及标点模型随包携带，
无需系统 Python、无需联网即可安装并听写。校对 GGUF 不随基础包分发；设置页提供显式下载、
进度和失败重试，下载完成后可启用本地校对。用户已明确授权这一范围。
发行包不得携带开发机个人配置、虚拟环境、缓存或 Git 元数据；模型只进忽略的分发产物，不入 Git。

## 实施

1. 按白名单复制应用文件，用固定独立 Python 构建干净依赖环境，携带指定基础模型；生成默认配置、ZIP 和 SHA256。
2. 发行安装入口只验证本地组件，不执行 pip 或模型下载；源码安装路径保留在线安装能力。
3. 设置页新增可选校对模型下载；下载工作在后台进行，不阻塞 Tk，跨窗口共享状态，失败不启用校对。
4. 在已启动的 Windows 10 虚拟机内验证：传入 ZIP、解压、运行 `install.bat`、启动程序，检查
   悬浮窗、托盘和设置页。若虚拟机没有音频输入，只把真实语音识别列为环境限制，不伪报通过。
5. 同步部署文档、CURRENT 与 CHANGELOG，运行 `python scripts/check_all.py --quiet`，完成独立审查。

## 验收标准

- 重复构建不会混入用户 `config.json`、虚拟环境或非白名单应用文件。
- 最终 ZIP 在全新目录解压，断网完成安装与语音、标点模型加载。
- 校对模型缺失时基本听写正常，设置中可显式下载并开启；真实 GUI 与音频验收分别记录。
- 最终产物路径、大小与 SHA256 可交付复核。
